# Patterns: the moves, one file each

A pattern is one move a video can make, named by the words a person would use to ask for it, with where it was observed in the seven studied videos, the measured numbers, what the move does to a viewer, a counter-example (who does not do it, or where it fails), and what it would need from a rig to be made. The files are the raw record from `deep/`, cut by move instead of by creator; nothing here says what we should do, which is `applied.md`'s job. Written 1 Oct 2026 from the deep pass (`deep/README.md` for the method, `deep/COMPARISON.md` for the numbers side by side). One video per creator, so every "always" below means "in the video studied."

Video ids: Fireship I_KVMFrUtPk; Casually Explained tqcThEqoYmA; How Money Works W6xkZy9nkaI; Stephane Maarek 10JKpg-eqZU; AWS Developers FAgmR9VV0GQ; IBM Technology bs1qPy_CWkM; Ken Burns and PBS g5WkOr565I4.

## Adding a pattern

Copy `PATTERN-TEMPLATE.md`. Name the file for the move, not the creator. Every claim under Observed carries a video id and a time; every number under The numbers comes from a shot log, a rhetoric map or an audio note in `deep/`, or says it is an estimate. The counter-example is required: a move with no counter-example is a rule, and rules live in `craft/`. Add the say-it-like phrases to the index table, which is sorted by phrase.
