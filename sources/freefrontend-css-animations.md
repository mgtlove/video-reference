## What it is, in two sentences

A curated listing of CSS-first animation pens (many pure HTML and CSS, some with a little JavaScript or GSAP), each with a description, the libraries it needs, browser support chips and a difficulty label. It is the better of the two FreeFrontend animation galleries for us, because pure CSS keyframes and transitions are the closest thing to what the rig already renders.

## Techniques this source points to

**Keyframes with staggered delays** (Bubble Preloader, Ripple Dot Grid, Spinning Cylinder, Tumbling Cubes, Text Marquee). Many siblings share one keyframe set and differ only by `animation-delay`, often negative so a loop starts mid-way. Rig questions, **unmeasured** for these pens: seekable through the Web Animations API (`document.getAnimations()` and setting `currentTime`), which the rig would have to do for every animation on the page, including the ones inside SVGs; deterministic by nature, no randomness in keyframes; offline, nothing fetched; tokens are easy since colours and sizes are already CSS; cost depends on filter and shadow use. This is the family the rig already uses, so the pens are references for choreography rather than new machinery.

**State switching through data attributes and transitions** (Shape Morphing Grid, Hamburger Icon, Folding Folder). A named state on the parent is changed and CSS transitions carry every child to its new place. The rig's timeline can set the attribute at a known time. **Unmeasured**: a transition started by an attribute change is seekable only through the Web Animations API once it is running, and a backward seek needs the previous state re-applied; the Morphing Grid's random picker must be replaced by a scripted sequence.

**Registered custom properties as the animated value** (Morphing Polyhedron, Progress Meters, Scramble). `@property` lets a number or angle be tweened by CSS and read by many rules at once, so one value drives a whole shape. **Unmeasured**: seekable like any CSS animation; browser support is Chromium and recent Safari and Firefox, which matters only for the render browser; tokens are natural here since the driving value is already a custom property.

**Scroll-driven animation timelines** (Circular Scramble, Sticky Text Reveal, Accordion Timeline). `animation-timeline: scroll()` binds progress to scroll position. For footage, scroll position is something the rig can set exactly, which would make these seekable by setting `scrollTop` rather than time. **Unmeasured**: whether a set scroll position renders the same frame every time, and whether headless rendering honours scroll timelines at all.

**SVG stroke drawing and shape reveal in CSS** (Clipboard Button, Border Trace, Flashlight, Cicada tree). Dash offset or a moving mask reveals a line or a region. Same idea as the rig's `drawOn()`, with the mask variant as a new shape of reveal. **Unmeasured**: mask and filter cost at 1920x1080. Related study: `studies/anime-js/` measured `createDrawable` for the JavaScript version.

**View Transitions for theme or layout switches** (Theme Toggle Navbar). The browser snapshots old and new states and animates between them. **Unmeasured**: the transition runs on the browser's own clock and the snapshot is taken at trigger time, so pausing it at an exact frame is doubtful; treat as inspiration for a wipe rebuilt with a clip path.

**Native controls restyled** (Progress Meters, Star Rating, Icon Bar). A real `progress`, checkbox or tab keeps its semantics and gains motion through pseudo-elements and SVG. Useful when a walkthrough shows a real control rather than a drawing of one. **Unmeasured**: vendor pseudo-elements render differently across browsers, which matters only for the render browser.

**Isometric diagram plates** (Floating Layers Diagram). Flat SVG plates offset in an isometric grid, each bobbing on a delay. A quiet version, no bob, is a clean architecture diagram. **Unmeasured**: the pen is React, so it is a rebuild, not a copy.

## Not for us, and why

- **Product and brand recreations**: Scroll-Driven macOS iOS Dock Concept (Jhey, https://codepen.io/jh3y/pen/LYaBRqL), 3D Star Wars Lightsaber Theme Toggle (Konstantin Denerz, https://codepen.io/konstantindenerz/pen/oNaGOpE), CSS Pixel Art Animation of a named game character (MercheDev, https://codepen.io/merchedev/pen/NWyBvzP). The team never recreates third-party products or characters. The dock pen's scroll-timeline scaling is a fine idea for our own row of cards.
- **Wall-clock dependence**: Haunted Grandfather Clock (Gemma Croad, https://codepen.io/GemmaCroad/pen/LEGWbLO) reads the real time, so two renders differ. Any clock in a video is a scripted value, never `Date`.
- **Unseeded randomness**: Dynamic CSS Shape Morphing Grid's state picker and the confetti in Interactive Eye-Tracking Subscription Form (nana, https://codepen.io/nanacodesign/pen/emJVeqw, needs canvas-confetti). The grid stays in the table because the transition part is sound; the picker goes.
- **Interaction with no meaning in footage**: Interactive Eye-Tracking Subscription Form (pupils follow the pointer and the text caret, rubber-band dragging), Hover-Reactive Parrot Character (coder787), Rollback Ball 3D Toggle Switch (Jon Kantner), CSS Hyper-Realistic Animated Glowing Bell (Rafa). Impressive as CSS drawing, but the point of each is a live response.
- **Loud pieces we would only turn down**: Cosmic 3D Galaxy Button (Jhey), Generative Glitch Cube Art (Konstantin Denerz), Sci-Fi Glowing Triangle Loader (Shane Burns), Glowing Chasing Squares CSS Loader (Adir). Nothing wrong with them; they do not survive the formal audience and add nothing the calmer pens above do not.
- **Dependencies to note before any copy**: Cicada page and Gravity Dashboard need GSAP and its plugins; Accordion Timeline needs Bootstrap and Font Awesome; Floating Layers needs React; Clipboard Button needs jQuery; Sticky Text Reveal bundles Tweakpane for its demo panel. None is copyleft as far as the gallery states, but each is a third-party library that needs its own `LICENCES.md` row before code moves, and every one of them would be loaded from a CDN in the pen, which the offline rule forbids. Rebuild the technique on the rig's own timeline instead.
- **Audio**: the Cicada page plays ambient sound. Footage has its own voice track; the pen's audio is ignored.
