## What it is, in two sentences

A curated listing of JavaScript-driven animation pens, mostly CodePen, each with a short description, the libraries it needs (GSAP and its plugins, Three.js, PixiJS, anime.js, Zdog, Lodash), browser support chips and a difficulty label. It is a place to find an effect by name and see who made it, not a source of code for the kit.

## Techniques this source points to

**SVG line drawing on a timeline** (Lasso Selection, Circle Unwrapping, Color Wave). A path's dash array is set to its length and the offset is tweened, so the stroke appears to be drawn; the wave variant tweens the offset on a mask instead of the path. This is what the rig's `drawOn()` already does by hand. Rig questions, all **unmeasured** for these pens: seekable if the tween lives on a GSAP timeline (`seek` and `progress` exist) and not on a `requestAnimationFrame` loop of its own; deterministic since there is no randomness in dash maths; offline only if the plugin files are local; tokens depend on whether stroke colour is a custom property; cost is small (one path). Study: `studies/anime-js/` covers the same idea with `createDrawable`, measured.

**Staggered entrances from a point or a grid** (Dot Grid, Blob Effect, Collage). Each element gets a delay computed from its index or its distance from a chosen point, and one timeline plays them all. A calm version, few pixels of travel and short delays, is the entrance the rig uses for cards. **Unmeasured**: seekable when the delays are part of one timeline; the Dot Grid's physics plugin is a closed-form tween, so it should repeat exactly, but that is a claim to test; cost depends on element count (hundreds of DOM nodes at 1920x1080 is the point to measure).

**Pointer-driven motion** (Footstep Trailer, Parallax Grid Mask, Floating Gallery). The pens read the live pointer. In footage there is no live pointer, so the rig's scripted cursor position must feed the same function of position. **Unmeasured**: these become seekable only once pointer position is itself a function of time; determinism follows from that; the Footstep pen adds elements as it goes, which a backward seek has to handle.

**FLIP layout change** (Morphing List, Flip Plugin Demo). Positions are measured before and after a layout change and the difference is tweened, so cards can go from a row to a grid without hand-placed keyframes. **Unmeasured**: seekable while the recorded tween is on a timeline; the measurement step must run once at build time, not on every seek, or backward seeks will re-measure the wrong state; plain files only if the Flip plugin is a local classic script.

**A value scrubbing a timeline** (Emotional Feedback Slider). The slider's value sets the timeline's progress. This is the rig's own model turned into a control, useful when a walkthrough shows a slider whose effect should be visible as motion. **Unmeasured**: seekable by construction.

**Camera over a larger room** (Floating Gallery). The scene is bigger than the frame and a transform on the wrapper pans it. This is the "cards and rooms" scene kind in one move. **Unmeasured**: cost of a large translated layer at full frame.

**Masked and sliced reveals** (Venetian Blinds, Parallax Grid Mask, Masked Video Hero). A clip or mask shape moves or scales to reveal content. Cheap and quiet when the shape is simple. **Unmeasured**: mask animation cost at 1920x1080; the video hero also needs a local video file.

**Word or letter splitting** (Puddle Reveal, JFK Wave, Collage's SplitText). Text is split into spans and each span is animated. The rig can do the split itself; a library is not needed. Two of these pens use a gooey SVG filter or `setInterval`, both of which need replacing. **Unmeasured**: filter cost at full frame; `setInterval` is not seekable at all.

**Loaders as progress indicators** (Penrose Loader). An infinite spinner can serve a walkthrough only if its rotation is a function of scene time or of a progress fraction, not of a free-running loop. **Unmeasured**.

## Not for us, and why

- **Product and brand recreations**: VisionOS Hexagonal App Grid Ripple (Konstantin Denerz, https://codepen.io/konstantindenerz/pen/poYVOpv), Disney+ Logo Animation (credit not shown on gallery, https://codepen.io/chrisgannon/pen/jOPXJqK), Bongo Cat Codes #2: Jamming (credit not shown on gallery, https://codepen.io/carolineartz/pen/qBOEzQa). The team never recreates third-party products or marks. The distance-based stagger inside the hexagon pen is an idea worth rebuilding on our own shapes; the Bongo Cat pen also uses randomised note particles.
- **WebGL and shader pieces**: Chromatic Aberration WebGL Sine Wave (Yuki), Halloween 2.5D Parallax Shader (Karim Maaloul), PixiJS Procedural GLSL Flame (Blake Bowen), Cinematic Zoom Blur Image Gallery and Shattering Image Gallery Transition (Kevin Levron), Interactive Spectral 3D Ghost Effect (Filipz), Interactive Canvas Particle Image Effect (Sikriti Dakua), Animated Camera Along a Path with Three.js (credit not shown on gallery). They need Three.js or PixiJS, run on their own clock, and the shader output can differ between GPUs, so identical renders across machines are not something we can promise (unmeasured). The Three.js camera pen also loads modules through an import map, which fails our plain-files rule.
- **Runtime network calls**: Infinite 3D Poster Scroll Wall (James Dow, https://codepen.io/photodow/pen/ExMXNrQ) fetches poster data from a live API. Out on the offline rule, whatever the effect.
- **Unseeded randomness**: Minimalist Canvas Animated Particle Background (Adrian Ortega), Rain Particle Effect with HTML Canvas (credit not shown on gallery), Dynamic Twinkling Particle System (credit not shown on gallery), Staggered Particle Blob Effect's auto-simulation mode. Canvas particle fields seeded from `Math.random` cannot be reproduced frame for frame unless rebuilt with a seeded generator (unmeasured for these pens; `studies/anime-js/` shows the seeded pattern that would replace them).
- **Interaction that means nothing in footage**: Draggable Zoom Grid Gallery using GSAP (Filip Zrnzevic) is built around inertia dragging and Web Audio triggers; Animated Coffee Cup Sticker (Noel Delgado) and Interactive Emotional Feedback Slider are character pieces whose charm is the live response. The slider stays in the table only for its scrub pattern.
- **Timers and free-running loops**: JFK Speech Text Wave uses `setInterval`; Air Balloon Cruise (credit not shown on gallery, https://codepen.io/braydoncoyer/pen/NWqYMmV) is an infinite ambient loop with no scene meaning. Neither can be put at an exact time as written.
- **Licence caution, not a rejection**: many pens here need GSAP plugins (DrawSVG, MorphSVG, SplitText, Flip, Physics2D, Inertia). GSAP is a third-party library with its own terms; nothing from it is copied into a study or the kit until `LICENCES.md` has a row for the exact version. The techniques above are rebuilt on the kit's own timeline or on a library that already has a row.
