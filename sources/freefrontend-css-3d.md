## What it is, in two sentences

A curated listing of pens that fake depth with CSS 3D transforms, `perspective` and `preserve-3d`, ranging from flipping cards and cubes to skeuomorphic switches and clocks. For us it is the reference for the "cards and rooms" scene kind: cards that flip, stacks that tilt, and a camera that moves around a shallow set, all in the DOM with no WebGL.

## Techniques this source points to

**Card flips and two-sided pieces** (Reversi Radio Buttons, Grow Up list, Card Trick, Team Carousel). A card is two faces under `preserve-3d` with `backface-visibility: hidden`, turned with `rotateY` inside a `perspective` parent. This is the plainest way to make a card reveal its other side in a "cards and rooms" scene. Rig questions, all **unmeasured** for these pens: seekable when the flip is a CSS animation or a timeline tween (Web Animations API for the CSS case); deterministic, no randomness; offline, nothing fetched; tokens easy since angle, duration and colours can be custom properties; cost is low for a handful of cards, and the FAQ on the page warns about z-fighting between overlapping faces, which a small `translateZ` offset fixes. Grow Up uses `setTimeout` for its entrance stagger, which must become timeline delays.

**Cubes and drums as panel holders** (Rolling Cube, Photo Cube, Dynamic Lighting Cube, Rotating Value Dial, Tumbling Cubes). Six panels transformed to face outward, then the cube itself turned. The lighting cube adds a small trick: opacity per face from its angle, so a turning cube reads as lit. The value dial is the same shape used as a counter. **Unmeasured**: the GSAP-driven ones seek through the timeline; the pure CSS ones through the Web Animations API; cost of many `preserve-3d` layers at 1920x1080.

**Pointer-driven tilt** (Holographic Card, Image Tilt, Photo Cube). The card's rotation is a function of pointer position; the CSS-only pen does it with hover zones. In footage the pointer is scripted, so the same function takes the rig's cursor position. **Unmeasured**: seekable only once pointer position is a function of time; the CSS-only zone version snaps between a few angles rather than following smoothly, which may read as steppy.

**Layered depth on a flat card** (Holographic Card, Illumination Card, Sphere). Two or three layers at different `translateZ` values, or gradient and shadow layers with no 3D at all, give a flat card volume. A quiet version, a lit edge and one floating element, suits a formal audience. **Unmeasured**: cost of large blurred shadows and blend modes at full frame.

**Parametric placement in CSS** (Orbit Gallery, Rotating Dial, Text Spiral). Trigonometric functions in CSS place n items around a circle or curve from one index variable, and an `@property` angle animates the whole set. Useful for laying many cards on a path without per-item numbers. **Unmeasured**: browser support for CSS trigonometry is recent, which matters for the render browser; seekable like any CSS animation.

**Rolling motion with a settle** (Rolling Cube, Tumbling Cubes). A quarter turn about a bottom edge, with the transform origin moved each step, plus an elastic ease at the end. A token stepping through stages of a process is the obvious use. **Unmeasured**: the elastic ease is a keyframe curve, so it repeats exactly.

**Digits that change physically** (Blocky Clock, Seven-Segment Clock, Value Dial). Counters where the number is a shape that moves rather than text that swaps. For footage the value must be set by the timeline, never by the clock. **Unmeasured**: the seven-segment pen builds its DOM by script and reads `Date`, so it is a rebuild.

**Section edges with gradient masks** (Zig-Zag Dividers). A single element with a conic gradient mask makes a cut-paper edge; depth of the teeth from a custom property. A subtle version is a nice transition edge. **Unmeasured**: mask cost is low for one element.

## Not for us, and why

- **Product and brand recreations**: Skeuomorphic Retro Casio F-91W Watch (Manz, https://codepen.io/manz/pen/KKWmWLb) recreates a named product. The team never recreates third-party products.
- **Wall-clock dependence**: Skeuomorphic Retro Casio F-91W Watch, Skeuomorphic Lunar Desk Calendar (Erica, https://codepen.io/ericadu/pen/GRZJjjE), Cube Clock with CSS 3D (credit not shown on gallery, https://codepen.io/stix/pen/mVXypr), Blocky Digital Clock and Neon 3D Seven-Segment Digital Clock as written. They read the real time, so two renders differ. The two clocks stay in the table only for their digit mechanics, with the value scripted.
- **Interaction with no meaning in footage**: 3D Neumorphic Pill Toggle Switch (ashif_6672), Neumorphic 3D Range Slider (Eric Johnson), Skeuomorphic Egg Toggle Switch and Skeuomorphic 3D Elastic Toggle Switch (Jon Kantner), Volumetric 3D CSS Toggle Switch, Pro-Mode Toggle Switch w/ Guard, Pro-Mode Toggle Switch with Guard (Softer), Vertical Rocker Switch (all credit not shown on gallery), 3D Glowing Button with CSS, Amateur Radio Badge 3D (credit not shown on gallery). Fine CSS drawing of hardware, but each is a control whose point is being touched; a walkthrough shows real chrome, not a stylised switch.
- **Audio and drag libraries**: Isometric 3D Mechanical Numpad plays click sounds and is React; Stellar 3D Slide Navigator (credit not shown on gallery, https://codepen.io/OathanRex/pen/VYvPzEY) uses the Web Audio API; Container Query Bookstore (credit not shown on gallery, https://codepen.io/mxbck/pen/XWMrMOp) is built on Dragula drag and drop and Web Components. Footage has its own voice track and no live pointer; the numpad stays in the table for its key-press drawing only.
- **Loud pieces we would only turn down**: 3D Warp Speed Tunnel (kept in the table as a transition, but far too much for a formal audience), Shimmer 3D Dodecahedron and Pure CSS 3D Animated Cat Model (credit not shown on gallery), Skeuomorphic Chess Pawn (Joshua van Boxtel). Showcases of CSS rendering with no scene of ours to serve.
- **Dependencies to note before any copy**: Warp Tunnel, Photo Cube and Lighting Cube need GSAP (and Draggable, dat.gui); Value Dial needs dat.gui; Numpad needs React. All would be CDN loads in the pen, which the offline rule forbids, and each needs its own `LICENCES.md` row before code moves. Nothing here is stated as copyleft, but the gallery's blanket MIT tag is not proof; the pen page is.
- **Seekability caution across the whole gallery**: none of these pens was run, so every "seekable" above is an opinion from the description. A CSS keyframe animation is in principle pausable at an exact time through the Web Animations API, but a pen that mixes script-driven class changes with CSS transitions will need each state change on the rig's timeline before a backward seek works. Measure before adopting.
