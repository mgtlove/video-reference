# video-reference

What makes an explainer video work, measured and written down so a person or an agent can build from it instead of from taste. Companion to [video-kit](https://github.com/mgtlove/video-kit), which turns three small data files made from this repo (rules, looks, a patterns index) into checks and menu choices.

Status: being rewritten from the study method, October 2026. Nothing from any creator is copied here: no frame, clip, logo or caption text; every note describes, measures and credits.

| Folder | What it holds |
|---|---|
| `catalog.md` | The index: techniques with verdicts, studies with measured results, sources |
| `studies/` | Runnable examples of animation libraries and techniques, each answering the same questions: seekable, deterministic, offline, token-driven, cost at 1080p |
| `craft/` | Composition, camera, colour, typography, pacing, accessibility: numbered rules, each with its source |
| `styles/` | Creators studied for voice, language, visuals and pacing; `deep/` holds shot logs, rhetoric maps and measured audio; `patterns/` holds one file per move, indexed by the phrase you would use to ask for it; `looks.json` the look packs |
| `sources/` | One note per site, article or repository read, with terms and credits |
| `licences.md` | Every copied library and every source's terms |

Method notes live beside the work they describe. Read `catalog.md` first.

Text and figures: CC BY 4.0. Code in `studies/`: MIT, with each library's own licence recorded in `licences.md`.
